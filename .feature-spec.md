# Feature Specification: Days to Christmas in the welcome greeting

GitHub Issue: https://github.com/joebew42/ex_chat/issues/32

## Summary

When a user joins a chat room, the welcome/greeting message they receive should
include a note about the number of days remaining until Christmas. The wording
changes as Christmas approaches:

- **Christmas day (Dec 25):** a celebratory message.
- **A few days before Christmas:** a friendly reminder to do the Christmas shopping.
- **Any other day:** the number of days remaining until Christmas.

### Examples (from the issue)

- `"Welcome Joe! It is 130 days to Christmas 🎅"`
- `"Welcome Joe! It is Christmas! Ho Ho merry Christmas 🎄"`
- `"Ho ho Joe! Have you done your Christmas shopping yet? 🎁"`

## Current behaviour

The welcome message is currently built inline in
`lib/ex_chat/use_cases/join_chat_room.ex`:

```elixir
UserSessions.notify(%{room: room, message: "welcome to the #{room} chat room, #{user_id}!"}, to: user_id)
```

The exact string is asserted in:
- `test/ex_chat/use_cases/join_chat_room_test.exs`
- `test/ex_chat/web/websocket_acceptance_test.exs`

## Design / Plan

To keep the existing base greeting intact and testable, extract the message
construction into a dedicated, pure module and append the Christmas clause to
the current welcome text.

### 1. New module: `ExChat.WelcomeMessage`

A pure function that builds the full welcome message. The current date is
injected as an optional argument to keep the logic deterministic and testable
(no hidden dependency on the system clock in tests).

```elixir
defmodule ExChat.WelcomeMessage do
  def for_user(room, user_id, today \\ Date.utc_today()) do
    "welcome to the #{room} chat room, #{user_id}! " <> christmas_clause(user_id, today)
  end
end
```

### 2. Christmas clause rules

Let `days` be the number of days from `today` to the next upcoming Christmas
(Dec 25). Computed against the current year; if `today` is after Dec 25, use
next year's Christmas.

- **`days == 0` (it is Christmas day):**
  `"It is Christmas! Ho Ho merry Christmas 🎄"`
- **`1 <= days <= 5` (a few days before Christmas):**
  `"Ho ho #{user_id}! Have you done your Christmas shopping yet? 🎁"`
- **otherwise:**
  `"It is #{days} days to Christmas 🎅"`

The "few days before" threshold is set to **5 days** as a sensible default.

### 3. Wire the module into the use case

Replace the inline string in `lib/ex_chat/use_cases/join_chat_room.ex` with a
call to `ExChat.WelcomeMessage.for_user(room, user_id)`.

### 4. Update existing tests

- `test/ex_chat/use_cases/join_chat_room_test.exs` — the notify assertion must
  account for the appended Christmas clause. Prefer asserting the base prefix or
  injecting a fixed date where possible.
- `test/ex_chat/web/websocket_acceptance_test.exs` — welcome-message assertions
  updated to reflect the new suffix (matching on the stable prefix to avoid
  date-dependent brittleness).

## Acceptance Criteria

- [ ] Joining a room returns a welcome message that includes the base greeting
      plus a Christmas clause.
- [ ] On Dec 25, the clause is the Christmas celebration message.
- [ ] Within 5 days before Christmas, the clause is the shopping reminder.
- [ ] On any other day, the clause states the number of days to Christmas.
- [ ] The number of days to Christmas is calculated correctly, including when
      the current date is after Dec 25 (counts to next year's Christmas).
- [ ] `ExChat.WelcomeMessage` is unit-tested with injected dates covering all
      three branches.
- [ ] Existing unit and acceptance tests are updated and pass.

## Implementation Notes

- `ExChat.WelcomeMessage` should be pure (date injected) so all branches can be
  unit-tested deterministically.
- Keep the existing lowercase "welcome to the ... chat room, ...!" base greeting
  to minimise churn in existing tests and preserve current behaviour.

## Progress

- [x] `ExChat.WelcomeMessage` — pure module building the welcome message with an
      injected date; unit-tested across all branches (ordinary day, Christmas
      day, few-days-before shopping reminder, and roll-over to next year's
      Christmas after Dec 25).
- [x] Wired `ExChat.WelcomeMessage.for_user/2` into

- [x] Updated `websocket_acceptance_test.exs` welcome-message assertions to match

### Key decisions

- The "few days before Christmas" window is `1..5` days, per the spec default.
- `JoinChatRoom`'s error-branch tests now `refute` any `UserSessions.notify`
  call (wildcard match) instead of referencing a now-stale exact message string.
- The repo does not enforce `mix format`; changes match the surrounding file
  style rather than reformatting existing code, to keep churn minimal.
